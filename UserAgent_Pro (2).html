ABOUT

UserAgent Pro builds internally consistent User-Agent strings for testing how your own website handles Facebook / Instagram in-app browsers and regular browsers. Each string is built in a fixed order: device → an OS version that device supports → matching build / WebKit → a compatible app version → random ids, locale and screen values.

No repeats: every generated string is remembered (hashed, in this browser's local storage). Generating again, or pressing "Generate" many times, will never return a string you already got. Use "Reset no-repeat history" to start over. If a selection simply has no more unique combinations (for example reduced desktop UAs), the tool stops early and tells you.

Data accuracy: device identifiers, iOS builds and Android build families are best-effort public data. Facebook/Instagram build ids (FBBV, version codes) change every release and were not verifiable offline: replace them with values captured from real devices in your own logs, using the Python script's --data-file, or edit the DATA block in this file.

Windows 10 and Windows 11 send the identical UA (Windows NT 10.0); the label is metadata only. Real variety on Windows comes from the browser (Chrome, Edge, Firefox), its major version, the Edge/Chrome build and patch numbers, 64-bit vs 32-bit (Win64; x64 / WOW64), and Windows 7 / 8.1 with older browsers. Edge is the strongest source: its Edg/ token always carries a full version, even when Chrome's is reduced. The country sets the locale used inside the string (FBLC / Instagram locale).
