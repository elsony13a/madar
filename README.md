# Madar v5 | مدار

منصة كورسات تعليمية أصلية، مستوحاة من نمط أسواق التعلم، وليست نسخة من Udemy ولا تستخدم علامته أو محتواه.

## ابدأ من غير AWS ومن غير أي دفع

افتح `Madar-Preview.html` في متصفح على الكمبيوتر. لو استلمته باسم `.html.txt` غيّر آخر الاسم إلى `.html` فقط. الملف مستقل ويحتوي الخطوط والتصميم والكود اللازم للمعاينة، ولا يحتاج تثبيت مكتبات.

- زر العربية / English يغير اللغة والاتجاه.
- الكتالوج فيه بحث وفلاتر للمجال ولغة الكورس.
- سجل جلسة تجريبية كطالب أو مدرس، من غير إيميل أو باسورد.
- جرّب كورسًا مجانيًا واحفظ تقدمك.
- في كورس مدفوع ارفع **صورة اختبار فقط**. الطلب يظل قيد المراجعة والكورس مقفول.
- زر `Test role` يفتح عرض المالك التجريبي. قبول الطلب يفتح الكورس، والرفض يتركه مقفولًا.
- دور المدرس يتيح إنشاء مسودة باللغتين، تعديلها ومراجعتها، تحديد السعر أو صفر للمجاني، ثم إرسالها لمراجعة المالك قبل النشر.

هذه أدوار محلية للاختبار فقط، وليست حسابات Cognito. كل البيانات في نفس المتصفح، ويمكن تعديلها من أدوات المطور. لا تضع محتوى خاصًا، إيصالًا حقيقيًا أو بيانات شخصية في المعاينة. لا يتم تحويل أي أموال. بعض عوارض الملفات داخل تطبيقات الهاتف لا تشغّل JavaScript؛ افتح الملف في متصفح على الكمبيوتر عندها.

## الجديد في النسخة الخامسة: مسودات اختبارات Bedrock

أضفت مصدر ربط اختياري من السيرفر عبر Converse لاقتراح أسئلة من دروس المدرّس النصية المحفوظة، ثم مراجعتها واعتمادها صراحة في المسودة قبل مراجعة المالك للنشر. التصحيح يظل حسابًا ثابتًا في السيرفر، لا نموذجًا لغويًا. الربط مغلق افتراضيًا؛ النموذج والمنطقة والتكلفة وصلاحيات الحساب لم تُحسم ولم يُستدعَ أي نموذج. المعاينة تستخدم مثالًا ثابتًا مكتوبًا مسبقًا، ليس نتيجة Bedrock ولا ناتجًا من دروسك. راجع `docs/V5-RELEASE.md` و`docs/BEDROCK.md` قبل التفكير في التفعيل. حدود الطلبات ليست ميزانية مالية.

## الجديد في النسخة الرابعة

الكورس الجديد لا يظهر للطلاب قبل مراجعة المالك من حساب منفصل. المدرّس يرسل محتوى مقفلًا للتعديل، ويمكنه سحب الطلب للتعديل. المالك يقرأ الدروس باللغتين والاختبار، ويعاين الفيديو الخاص في مصدر AWS، ثم يوافق وينشر أو يعيده للمسودة بملاحظة. ربط القرار برقم إرسال يمنع الموافقة على نسخة تغيّرت بعد فتح شاشة المراجعة. الكورسات القديمة المنشورة لا تُلغى ولا تُنقل للمراجعة تلقائيًا.

أضفت بلاغات للطلاب المشتركين عن المحتوى أو النقاش، وقائمة بلاغاتهم ونتيجة مراجعة المالك. حل البلاغ لا يخفي المحتوى ولا يسترد الأموال ولا يغيّر الاشتراك تلقائيًا. مراجعة النشر ليست فحص ملفات ضارة أو تصريح حقوق نشر. بيانات وسعر الكورس المنشور يظلان قابلين للتعديل كما في النسخة السابقة دون مراجعة ثانية؛ محتوى الدروس والاختبار ثابت. تفاصيل التجربة والحدود في `docs/V4-RELEASE.md`.

## الجديد في النسخة الثالثة

ملاحظات خاصة لكل درس مع حفظ يدوي، وأسئلة للطلاب المشتركين داخل الكورس، وردود من مدرّس الكورس نفسه، وإخفاء واستعادة النقاش كاملًا بواسطة المالك. أضفت لوحة للمدرّس بعدد كورساته وتقييماته المقبولة والأسئلة التي لم يُرد عليها وطلبات الدفع المقبولة. مبالغ الطلبات ليست أرباحًا مؤكدة ولا تسويات ولا تحويلات. الملاحظات معزولة بالحساب في مصدر AWS، لكن كل أدوار المعاينة تشترك في بيانات المتصفح فلا تستخدمها لمعلومات خاصة. تفاصيل التجربة والحدود في `docs/V3-RELEASE.md`.

## الجديد في النسخة الثانية

أضفت اختبارات ينشئها المدرّس مع تصحيح في السيرفر، وسجل إكمال قابل للتنزيل بعد إكمال الدروس والاختبار إن وُجد، وتقييمات طلاب تمر على مراجعة المالك، وكورسات محفوظة، وتعديل بيانات وسعر الكورس المنشور دون تغيير محتواه أو تقدم الطلاب. الشهادات غير معتمدة والأسماء ذاتية الإدخال ولا يوجد رابط تحقق عام. تفاصيل التجربة والحدود في `docs/V2-RELEASE.md`.

كورس السحابة في المعاينة لديه اختبار أصلي من ثلاثة أسئلة. جرّب إكماله ثم تنزيل سجل إكمال. هذه عينة محلية، ومفاتيح إجاباتها ليست سرية في وضع demo. الكورسات الحقيقية على AWS لا تُضاف لها اختبارات أو بيانات تجريبية تلقائيًا.

## الكود المنظم

```text
web/                 الواجهة، قاموس اللغات، الربط، وصفحات الأدوار
backend/             منطق الصلاحيات والدفع والتعلم + موصلات AWS
backend/test/        اختبارات القواعد الأمنية والعمل
scripts/             بناء المشروع وإعداد config من مخرجات الـstack
build/backend/       نسخة Lambda مجمعة وجاهزة للتعبئة، ليست منشورة
dist/                نسخة واجهة demo مبنية، ليست منشورة
template.yaml        قالب SAM اختياري لكل موارد النسخة الأولى
docs/SETUP.md        التشغيل المحلي ثم مسار AWS واحد
docs/SECURITY.md     حدود الحماية والتشغيل الفعلي
docs/FEATURES.md     ما تم وما لم يتم، وخريطة التطوير
docs/V4-RELEASE.md   دليل النسخة المجمعة وخطوات تجربة الإضافات
```

للتطوير تحتاج Node.js 22 وnpm:

```bash
npm ci
npm --prefix backend ci
npm run dev
```

ثم افتح `http://localhost:8080/`. هذا لا ينشئ موارد AWS. لو المنفذ مستخدم غيّره محليًا، لكن عند اختبار Cognito يجب أن تطابق callback URL وإعدادات CORS المنفذ الجديد بالضبط.

```bash
npm test                  # اختبارات الـbackend دون الاتصال بحساب AWS
npm run build             # بناء الواجهة
npm run build:backend     # تجميع Lambda، من غير نشر
npx playwright install chromium
npm run test:ui           # سيناريو المتصفح المحلي
```

## الفرق بين الجاهز محليًا وبين الربط الحقيقي

المعاينة المحلية تعمل في وضع `demo`. يوجد كود AWS فعلي وقالب موارد مترابط، لكن **لم يتم نشره أو اختباره على حساب AWS حقيقي**. نجاح البناء والاختبارات المحلية ليس دليلًا على نجاح Cognito أو رفع S3 أو CloudFront على حسابك. لا توجد أي أرقام user pool أو client أو API من مشروع سابق.

القالب يقترح: Cognito + HTTP API + Lambda خارج VPC + DynamoDB + S3 خاص مع versioning للملفات + S3 خاص وCloudFront للواجهة. لا يحتاج RDS أو NAT لهذا الإصدار. اختيار هذه البنية اقتراح في المصدر، وليس موارد تم إنشاؤها.

اقرأ `docs/SETUP.md` قبل أي نشر. النشر ينشئ موارد يمكن أن تتحاسب عليها. لا يوجد وعد أنها مجانية، والدفع الحقيقي مغلق افتراضيًا.

## What this is

A bilingual learning-platform fifth version with an original identity. The demo works locally. The source includes a proposed serverless backend and infrastructure template, not an already-connected production system. Paid access is gated by a backend enrollment entitlement created only after an authorized manual review. Admin is not a self-signup role. See the feature matrix and acceptance checks before deployment.
